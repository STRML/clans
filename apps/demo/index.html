Clans

This is a client-only demo. It needs a Clans server to connect to.

Run one yourself: pnpm dev:server from a clone of github.com/STRML/clans, then reload this page with ?server=ws://your-host:7777 appended to the URL.

This page is served over HTTPS, so a plain ws:// connection only works for a secure-context host like localhost or 127.0.0.1 -- a remote server needs wss:// (a TLS-terminating proxy in front of it).
