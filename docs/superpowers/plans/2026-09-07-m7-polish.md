# Milestone 7: Command circuit, audio, voice binds, polish, Playwright suite, GitHub Pages demo

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Clans becomes the shipped v1 the spec describes. A player opens the commander map (`C`, already real), clicks a point, and orders their bots to attack, defend, or repair there — the order is a wire message, lives on the server, and a bot's own goal selection reads it as a priority override, never as client-side state a bot could disagree with. Weapons, jets, skiing, footsteps, base destruction, and flag capture all make sound, synthesized in the browser from oscillators and noise, no shipped audio file. A quick-chat voice menu (`V`) speaks nine T2-style lines through the Web Speech API, played locally for your own action and, for everyone else, replayed from a short broadcast event code rather than an audio stream. Four filed issues that read as playability or command-circuit-adjacent bugs get fixed with red tests; the rest stay open with a stated reason. The Playwright suite is audited and extended so a full human journey — join, move, fight, capture, mount a vehicle, see a bot fight — has real, non-scripted coverage, not just a debug teleport hook. `apps/demo` builds the client as a static site with a "point it at your own server" flow and a GitHub Actions workflow deploys it to Pages on every push to `main`. README and NOTICE close out the project: a verified one-command run and full source credit across all seven milestones.
**Architecture:** `packages/protocol` gains one client→server message (`CommandOrder`), one more (`VoiceBind`), one `EventKind` (`VoiceBindPlayed`), and one `WorldExtras` array (`orders`, at most 2 entries — one per team). `packages/server` gains `orders.ts` (an `OrderBoard`: one `TeamOrder | null` per team, TTL-expired, never part of `World` or `hashWorld` — the same "runtime memory, not sim state" convention M6's real, merged `BotManager` already established) and wires `handleCommandOrder`/`handleVoiceBind` into `net.ts` next to the existing `handleLoadout`/`handleVehicleSpawn`. `packages/bots` (real, merged at `713469d` — see Baseline) gains an order-aware `decideGoal` overload: this plan extends `decideGoal`/`stepBot`/`stepBots`/`BotManager`/`stepBotManager`'s real signatures, cited by file and line below. `packages/client` gains `audio.ts` (a Web Audio synthesis engine, no decoded audio files, no `AudioBufferSourceNode` pointed at a fetched asset), `voicebinds.ts` (the quick-chat menu and `SpeechSynthesisUtterance` playback), and extends `commander-map.ts` with click-to-order and order-marker rendering. `apps/demo` is new: a thin Vite app that imports `@clans/client`'s existing bootstrap and reads a `?server=` query param.
**Tech Stack:** the M1-M6 stack unchanged. No new runtime dependency anywhere — Web Audio and Web Speech are browser platform APIs, not packages. `apps/demo` adds one more Vite entry point inside the existing pnpm workspace, no new tool.

## Global Constraints

- **An order is a message, not client-side state — enforced by never rendering an order marker from the click itself.** `commander-map.ts`'s click handler builds a `CommandOrderMessage` and sends it; it does not add a marker to its own draw list. The only order a client ever renders is one it decoded off `WorldExtras.orders` in the most recent snapshot — server-authoritative round trip, not optimistic local state. A player who clicks and immediately closes the map (`C` again) before the next snapshot arrives sees no marker, which is correct: the order may not have reached the server at all.
- **Bot order runtime memory lives with the `OrderBoard`, not in `World`, mirroring `BotManager`'s own memory (M6 Global Constraints, first bullet).** `hashWorld` gains no new field this milestone; `packages/sim` is untouched (confirmed above: Repair-order behavior reuses `applyLoadoutRequest` and the existing Repair Pack beam, and command/attack/defend orders are pure goal-selection data a bot's own `PlayerInput` output already carries).
- **One active order per team, no queue.** A second `CommandOrder` for a team that already has one simply replaces it (`issueOrder` overwrites, never appends) — matches the given scope's "a simple order" framing and avoids designing a queue-eviction policy nobody asked for.
- **Voice binds broadcast a line id, never audio.** The wire payload is one `u8` (`VoiceBindMessage.lineId`); every client, including the sender, resolves that id to text through the same `VOICE_LINES` table and calls its own local `SpeechSynthesis`. Two players on different OSes may render the line in different synthesized voices — accepted, not a bug: the spec's own words are "so other clients synthesize the same line locally," not "sound identical."
- **Audio synthesis only, no shipped or fetched sample.** The given scope is explicit ("oscillators/noise generators rather than shipped audio files"), narrower than the spec's own text ("CC0 samples where needed"). This plan follows the given scope: `audio.ts` never calls `fetch`, never decodes an `AudioBuffer` from a file, and `NOTICE.md` gains no new audio-source credit — see the "ours" table for the one-line rationale.
- **Every ESLint `complexity: 10` / `max-depth: 3` budget holds.** `audio.ts`'s per-effect synthesis is one small factory function per sound (`spinfusorFire(ctx, gain)`, `chaingunFire(ctx, gain)`, …), never one large `playSound(kind)` switch with the oscillator graph inlined per case — mirrors `movement.ts`'s own small-named-function split M6 already cites as this codebase's own precedent.
- **`apps/demo` never bundles or references Sierra data of its own.** It imports `@clans/client`'s existing bootstrap (which already reads `assets/out/`, committed to git) — no new asset fetch, no new `NOTICE.md` entry, no Blender or network step added to the Pages build.

## Numbers this plan picks ("ours")

| Number | Value | Why | Where |
|---|---|---|---|
| `ORDER_TTL_S` | 90 | Long enough for a bot to path across the 2 km Katabatic map at ski speed and still act on the order once it arrives; short enough that a directive from ten minutes ago doesn't silently steer a bot's behavior in a match that has moved on | Task 2 |
| `ORDER_ARRIVE_RADIUS` | 6 m | An order's target is a raw canvas click converted to world space, not a graph node — bigger than M6's own `WAYPOINT_REACHED_RADIUS` (4 m) since a click will rarely land exactly on a landmark | Task 3 |
| `MAX_SNAPSHOT_ORDERS` | 2 | One active order per team, matching the "one order, no queue" decision above | Task 1 |
| `VOICE_LINE_COUNT` | 9 | A flat 1-9 menu (matching the existing weapon-slot digit precedent, `input.ts:88-93`) rather than T2's own multi-level VGS radial, which this milestone's scope doesn't ask for | Task 6 |
| `VOICE_BIND_COOLDOWN_TICKS` | 32 (1 s at the 32 ms tick) | Stops one player's key-mash from flooding `recentEvents` and every client's speech queue; short enough that legitimate rapid-fire quick-chat (a kill confirm right after a flag touch) still gets through | Task 2 |
| `AUDIO_MASTER_GAIN` | 0.6 | Default master `GainNode` value — headroom under 1.0 so overlapping synthesized effects (chaingun fire plus footsteps plus a jet loop) don't clip the Web Audio output | Task 7 |
| `FOOTSTEP_INTERVAL_S` | 0.35 | Cadence for synthesized footsteps while running on ground; picked to read as a jog at Light armor's 15 m/s cap without sounding like a rattling machine-gun of clicks — not a T2 script number, since T2's own footstep timing comes from animation authoring, not a datablock field | Task 7 |

```ts
export interface TeamOrder {
  team: number;
  kind: OrderKind;
  x: number;
  z: number;
  expiresAtTick: number;
}

export interface OrderBoard {
  byTeam: Map<number, TeamOrder>;
}

export function createOrderBoard(): OrderBoard {
  return { byTeam: new Map() };
}

export function issueOrder(
  board: OrderBoard,
  team: number,
  kind: OrderKind,
  x: number,
  z: number,
  tick: number,
): void {
  board.byTeam.set(team, {
    team,
    kind,
    x,
    z,
    expiresAtTick: tick + Math.round(ORDER_TTL_S / FIXED_DT),
  });
}

export function currentOrder(board: OrderBoard, team: number, tick: number): TeamOrder | null {
  const order = board.byTeam.get(team);
  if (!order || tick > order.expiresAtTick) return null;
  return order;
}
```

```ts
function orderGoal(
  world: World,
  runtime: BotRuntimeState,
  order: TeamOrder,
): { position: Vec3; key: string } | null {
  if (order.kind === OrderKind.Repair) {
    if (world.players.hasRepairPack[runtime.playerId] !== 1) {
      const stationId = findNearestFriendlyStation(world, runtime.playerId);
      if (stationId === null) return { position: { x: order.x, y: 0, z: order.z }, key: 'order:repair-equip' };
      const base = stationId * 3;
      return {
        position: {
          x: world.baseObjects.position[base] ?? 0,
          y: world.baseObjects.position[base + 1] ?? 0,
          z: world.baseObjects.position[base + 2] ?? 0,
        },
        key: 'order:repair-equip',
      };
    }
    return { position: { x: order.x, y: 0, z: order.z }, key: 'order:repair' };
  }

  order: TeamOrder | null,

  // Real decideGoal's existing order (brain.ts:143-152): heal is checked first, unconditionally

  // any active order (see this task's own "judgment call" note above).

export function maybeEquipRepairPack(world: World, botId: number): void {
  const stationId = findNearestFriendlyStation(world, botId);
  if (stationId === null) return;
```

```ts
export function sensedEnemyIds(
  players: readonly PlayerPosition[],
  localTeam: number,
  circles: readonly SensorCircle[],
  world: World,
): number[] {
  const ids: number[] = [];
  for (const player of players) {
    if (!player.alive || player.team === localTeam) continue;
    if (!insideAnyCircle(player.x, player.z, circles)) continue;
    // Reuse the sensor circle's own center as the observing point -- a sensor detects
    // along its own line of sight, not the local player's. Every circle covering this
    // enemy is checked; one clear line from any of them is enough.
    const clear = circles.some(
      (c) =>
        Math.hypot(player.x - c.x, player.z - c.z) <= c.radius &&
        hasLineOfSight(world, { x: c.x, y: 0, z: c.z }, { x: player.x, y: 0, z: player.z }),
    );
    if (clear) ids.push(player.id);
  }
  return ids;
}

export function canvasToWorld(
  ctx: CanvasRenderingContext2D,
  missionArea: { minX: number; minZ: number; width: number; depth: number },
  canvasX: number,
  canvasY: number,
): { x: number; z: number } {
  const { width, height } = ctx.canvas;
  return {
    x: missionArea.minX + (canvasX / width) * missionArea.width,
    z: missionArea.minZ + (canvasY / height) * missionArea.depth,
  };
}

export function drawOrderMarkers(
  ctx: CanvasRenderingContext2D,
  assets: Pick<KatabaticAssets, 'scene'>,
  orders: readonly OrderSnapshotData[],
  localTeam: number,
  toCanvas: (x: number, z: number) => [number, number],
): void {
  const own = orders.find((o) => o.team === localTeam);
  if (!own) return;
  const [cx, cy] = toCanvas(own.x, own.z);
  ctx.strokeStyle = own.kind === OrderKind.Attack ? '#ff4444' : own.kind === OrderKind.Defend ? '#44aaff' : '#44ff88';
  ctx.lineWidth = 2;
  ctx.beginPath();
  ctx.arc(cx, cy, 10, 0, Math.PI * 2);
  ctx.stroke();
}
```

```ts
import { WeaponId, type Vec3 } from '@clans/sim';

export const AUDIO_MASTER_GAIN = 0.6; // Ours -- see this plan's "ours" numbers table.
export const FOOTSTEP_INTERVAL_S = 0.35; // Ours.

interface AudioLike {
  context: Pick<
    AudioContext,
    | 'currentTime'
    | 'destination'
    | 'createOscillator'
    | 'createGain'
    | 'createBufferSource'
    | 'createBuffer'
    | 'createBiquadFilter'
    | 'createPanner'
  >;
}

function noiseBuffer(context: AudioLike['context'], seconds: number): AudioBuffer {
  const sampleRate = 44100;
  const buffer = context.createBuffer(1, Math.floor(sampleRate * seconds), sampleRate) as AudioBuffer;
  const data = buffer.getChannelData(0);
  for (let i = 0; i < data.length; i += 1) data[i] = Math.random() * 2 - 1;
  return buffer;
}

function envelope(
  context: AudioLike['context'],
  gainNode: GainNode,
  peak: number,
  attackS: number,
  releaseS: number,
): void {
  const now = context.currentTime;
  gainNode.gain.setValueAtTime(0, now);
  gainNode.gain.linearRampToValueAtTime(peak, now + attackS);
  gainNode.gain.exponentialRampToValueAtTime(0.001, now + attackS + releaseS);
}

/** Sawtooth 220 -> 90 Hz over 120 ms, plus a 60 ms noise burst -- a low thud with an edge. */
function spinfusorFire(context: AudioLike['context'], master: GainNode): void {
  const osc = context.createOscillator() as OscillatorNode;
  const gain = context.createGain() as GainNode;
  osc.type = 'sawtooth';
  osc.frequency.setValueAtTime(220, context.currentTime);
  osc.frequency.exponentialRampToValueAtTime(90, context.currentTime + 0.12);
  envelope(context, gain, 0.5, 0.005, 0.12);
  osc.connect(gain).connect(master);
  osc.start();
  osc.stop(context.currentTime + 0.15);
}

/** Square 900 Hz, 12 ms decay -- a short dry click per shot. */
function chaingunFire(context: AudioLike['context'], master: GainNode): void {
  const osc = context.createOscillator() as OscillatorNode;
  const gain = context.createGain() as GainNode;
  osc.type = 'square';
  osc.frequency.setValueAtTime(900, context.currentTime);
  envelope(context, gain, 0.25, 0.001, 0.012);
  osc.connect(gain).connect(master);
  osc.start();
  osc.stop(context.currentTime + 0.02);
}

/** Sine 60 Hz thump over 200 ms plus a low-passed noise tail. */
function mortarFire(context: AudioLike['context'], master: GainNode): void {
  const osc = context.createOscillator() as OscillatorNode;
  const gain = context.createGain() as GainNode;
  osc.type = 'sine';
  osc.frequency.setValueAtTime(60, context.currentTime);
  envelope(context, gain, 0.6, 0.01, 0.2);
  osc.connect(gain).connect(master);
  osc.start();
  osc.stop(context.currentTime + 0.25);
}

/** Sine sweep 800 -> 2000 Hz over 80 ms -- an instant "zap" for the hitscan Laser Rifle. */
function laserFire(context: AudioLike['context'], master: GainNode): void {
  const osc = context.createOscillator() as OscillatorNode;
  const gain = context.createGain() as GainNode;
  osc.type = 'sine';
  osc.frequency.setValueAtTime(800, context.currentTime);
  osc.frequency.exponentialRampToValueAtTime(2000, context.currentTime + 0.08);
  envelope(context, gain, 0.35, 0.002, 0.08);
  osc.connect(gain).connect(master);
  osc.start();
  osc.stop(context.currentTime + 0.1);
}

const WEAPON_SYNTH: Partial<Record<WeaponId, (ctx: AudioLike['context'], master: GainNode) => void>> = {
  [WeaponId.Spinfusor]: spinfusorFire,
  [WeaponId.Chaingun]: chaingunFire,
  [WeaponId.Mortar]: mortarFire,
  [WeaponId.LaserRifle]: laserFire,
  [WeaponId.Blaster]: chaingunFire, // closest existing timbre; no distinct spec guidance
};

export interface AudioEngine {
  weaponFire(weaponId: WeaponId, position: Vec3): void;
  explosion(position: Vec3): void;
  flagCapture(): void;
  flagTouch(): void;
  setJetting(playerId: number, active: boolean, energyFraction: number): void;
  setSkiing(playerId: number, active: boolean, speed: number): void;
  footstep(position: Vec3): void;
  setStationHum(id: number, position: Vec3, active: boolean): void;
  dispose(): void;
}

export function createAudioEngine(listener: AudioLike): AudioEngine {
  const { context } = listener;
  const master = context.createGain() as GainNode;
  master.gain.value = AUDIO_MASTER_GAIN;
  master.connect(context.destination);
  const loops = new Map<string, { stop(): void }>();

  return {
    weaponFire(weaponId, _position): void {
      (WEAPON_SYNTH[weaponId] ?? chaingunFire)(context, master);
    },
    explosion(_position): void {
      const src = context.createBufferSource() as AudioBufferSourceNode;
      src.buffer = noiseBuffer(context, 0.4);
      const filter = context.createBiquadFilter() as BiquadFilterNode;
      filter.type = 'lowpass';
      filter.frequency.setValueAtTime(800, context.currentTime);
      filter.frequency.exponentialRampToValueAtTime(80, context.currentTime + 0.4);
      const gain = context.createGain() as GainNode;
      envelope(context, gain, 0.7, 0.005, 0.4);
      src.connect(filter).connect(gain).connect(master);
      src.start();
    },
    flagCapture(): void {
      [523, 659, 784].forEach((freq, i) => {
        const osc = context.createOscillator() as OscillatorNode;
        const gain = context.createGain() as GainNode;
        osc.type = 'square';
        osc.frequency.setValueAtTime(freq, context.currentTime + i * 0.1);
        envelope(context, gain, 0.3, 0.005, 0.1);
        osc.connect(gain).connect(master);
        osc.start(context.currentTime + i * 0.1);
        osc.stop(context.currentTime + i * 0.1 + 0.12);
      });
    },
    flagTouch(): void {
      const osc = context.createOscillator() as OscillatorNode;
      const gain = context.createGain() as GainNode;
      osc.type = 'sine';
      osc.frequency.setValueAtTime(440, context.currentTime);
      envelope(context, gain, 0.3, 0.005, 0.08);
      osc.connect(gain).connect(master);
      osc.start();
      osc.stop(context.currentTime + 0.1);
    },
    setJetting(playerId, active, energyFraction): void {
      const key = `jet:${String(playerId)}`;
      if (!active) {
        loops.get(key)?.stop();
        loops.delete(key);
        return;
      }
      if (loops.has(key)) return;
      const src = context.createBufferSource() as AudioBufferSourceNode;
      src.buffer = noiseBuffer(context, 1);
      src.loop = true;
      const filter = context.createBiquadFilter() as BiquadFilterNode;
      filter.type = 'bandpass';
      filter.frequency.value = 300 + energyFraction * 200;
      const gain = context.createGain() as GainNode;
      gain.gain.value = 0.3;
      src.connect(filter).connect(gain).connect(master);
      src.start();
      loops.set(key, { stop: () => src.stop() });
    },
    setSkiing(playerId, active, speed): void {
      const key = `ski:${String(playerId)}`;
      if (!active) {
        loops.get(key)?.stop();
        loops.delete(key);
        return;
      }
      if (loops.has(key)) return;
      const src = context.createBufferSource() as AudioBufferSourceNode;
      src.buffer = noiseBuffer(context, 1);
      src.loop = true;
      const filter = context.createBiquadFilter() as BiquadFilterNode;
      filter.type = 'bandpass';
      filter.frequency.value = 200 + Math.min(speed, 20) * 50;
      const gain = context.createGain() as GainNode;
      gain.gain.value = Math.min(speed / 20, 1) * 0.25;
      src.connect(filter).connect(gain).connect(master);
      src.start();
      loops.set(key, { stop: () => src.stop() });
    },
    footstep(_position): void {
      const src = context.createBufferSource() as AudioBufferSourceNode;
      src.buffer = noiseBuffer(context, 0.03);
      const filter = context.createBiquadFilter() as BiquadFilterNode;
      filter.type = 'lowpass';
      filter.frequency.value = 400;
      const gain = context.createGain() as GainNode;
      envelope(context, gain, 0.2, 0.001, 0.03);
      src.connect(filter).connect(gain).connect(master);
      src.start();
    },
    setStationHum(id, _position, active): void {
      const key = `hum:${String(id)}`;
      if (!active) {
        loops.get(key)?.stop();
        loops.delete(key);
        return;
      }
      if (loops.has(key)) return;
      const oscA = context.createOscillator() as OscillatorNode;
      const oscB = context.createOscillator() as OscillatorNode;
      oscA.type = 'sine';
      oscB.type = 'sine';
      oscA.frequency.value = 55;
      oscB.frequency.value = 110;
      const gain = context.createGain() as GainNode;
      gain.gain.value = 0.05;
      oscA.connect(gain).connect(master);
      oscB.connect(gain);
      oscA.start();
      oscB.start();
      loops.set(key, {
        stop: () => {
          oscA.stop();
          oscB.stop();
        },
      });
    },
    dispose(): void {
      for (const loop of loops.values()) loop.stop();
      loops.clear();
      master.disconnect();
    },
  };
}
```
